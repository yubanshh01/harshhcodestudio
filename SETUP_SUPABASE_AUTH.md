# Supabase Auth Setup Guide for Admin Portal\n\nThis guide explains how to set up Supabase authentication for the admin portal.\n\n## Step 1: Create a Supabase Project\n\n1. Go to [supabase.com](https://supabase.com)\n2. Sign up / Log in\n3. Create a new project\n4. Save your project URL and anon key\n\n## Step 2: Get Your Supabase Credentials\n\n1. In Supabase dashboard, go to **Settings** → **API**\n2. Copy:\n   - **Project URL** (e.g., `https://xxxxx.supabase.co`)\n   - **Anon Key** (public key for frontend)\n\n## Step 3: Update login.html and admin.html\n\nReplace these placeholders in both files:\n\n```javascript\nconst SUPABASE_URL = 'https://YOUR_SUPABASE_URL.supabase.co';\nconst SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';\n```\n\nWith your actual Supabase credentials.\n\n## Step 4: Create Auth Users in Supabase\n\n1. In Supabase dashboard, go to **Authentication** → **Users**\n2. Click **\"Invite user\"**\n3. Enter admin email and password\n4. Click **User** → **Custom claims** (if available) or use user metadata\n5. Set metadata:\n   ```json\n   {\n     \"role\": \"admin\"\n   }\n   ```\n\n**OR** Create user via SQL:\n\n```sql\n-- Run this in Supabase SQL Editor\nINSERT INTO auth.users (email, encrypted_password, user_metadata, confirmed_at)\nVALUES (\n  'harsh@example.com',\n  crypt('your_secure_password', gen_salt('bf')),\n  '{\"role\": \"admin\"}'::jsonb,\n  now()\n);\n```\n\n## Step 5: Create Posts Table\n\nRun this SQL in Supabase:\n\n```sql\nCREATE TABLE posts (\n  id BIGINT PRIMARY KEY,\n  title TEXT NOT NULL,\n  tag TEXT,\n  content TEXT NOT NULL,\n  img TEXT,\n  date TEXT,\n  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,\n  created_at TIMESTAMP DEFAULT now()\n);\n\n-- Enable RLS\nALTER TABLE posts ENABLE ROW LEVEL SECURITY;\n\n-- Allow authenticated users to read\nCREATE POLICY \"Public read posts\" ON posts\n  FOR SELECT USING (true);\n\n-- Allow only author to delete/update\nCREATE POLICY \"Author can update posts\" ON posts\n  FOR UPDATE USING (auth.uid() = user_id);\n\nCREATE POLICY \"Author can delete posts\" ON posts\n  FOR DELETE USING (auth.uid() = user_id);\n\n-- Allow admin to insert\nCREATE POLICY \"Admin can insert posts\" ON posts\n  FOR INSERT WITH CHECK (\n    auth.uid() IN (\n      SELECT id FROM auth.users \n      WHERE user_metadata->>'role' = 'admin'\n    )\n  );\n```\n\n## Step 6: Test the Login\n\n1. Go to `login.html` in your website\n2. Enter the admin email and password you created\n3. You should be redirected to `admin.html`\n4. Try creating a post\n\n## Security Best Practices\n\n✅ **Do:**\n- Use strong passwords for admin accounts\n- Enable **2FA** in Supabase authentication settings\n- Review **Row Level Security (RLS)** policies\n- Keep Supabase keys secure (never commit them)\n- Use environment variables in production\n- Enable **Email Confirmations** for new admin users\n- Regularly audit admin users and remove inactive ones\n\n❌ **Don't:**\n- Expose Supabase keys in public code\n- Use weak passwords\n- Give admin role to non-admins\n- Disable RLS policies\n- Store sensitive data in user_metadata\n\n## Environment Variables Setup (Production)\n\nFor production, use environment variables instead of hardcoding:\n\n```javascript\nconst SUPABASE_URL = process.env.REACT_APP_SUPABASE_URL;\nconst SUPABASE_ANON_KEY = process.env.REACT_APP_SUPABASE_ANON_KEY;\n```\n\n## Troubleshooting\n\n**\"Supabase not configured\" error:**\n- Check that SUPABASE_URL and SUPABASE_ANON_KEY are set correctly\n- Verify your Supabase project is active\n\n**\"Access denied: Admin role required\" error:**\n- Make sure user's metadata includes `{\"role\": \"admin\"}`\n- Check RLS policies in Supabase dashboard\n\n**Posts not saving:**\n- Verify `posts` table exists and RLS policies allow INSERT\n- Check browser console for detailed errors\n- Ensure user_id is properly set\n\n## Support\n\n- [Supabase Docs](https://supabase.com/docs)\n- [Supabase Auth Guide](https://supabase.com/docs/guides/auth)\n- [RLS Guide](https://supabase.com/docs/guides/auth/row-level-security)\n"
